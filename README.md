# Node Panel

Panneau pour gérer plusieurs projets Node.js sur une machine, par WyattLewisTV.

Téléchargements : voir [Releases](../../releases/latest).

- **Windows** : `Node-Panel-Setup-<version>.exe` (installateur, mises à jour automatiques)
- **Linux** : `node-panel-linux-<version>.tar.gz` (`npm install`, puis `npm start` ; mises à jour avec `npm run update`)
